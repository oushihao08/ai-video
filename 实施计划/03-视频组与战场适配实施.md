## 03A：先做设计与无声视频基础

1. 定义 story-video 的两种进入方式：完整视频在骨架/正文阶段参与；已有稿/音频/场景可直接接入。明确哪部分缺输入，先完成不依赖该输入的工作。
2. 消费00的句段与初始 shots约定，生成可读视听表：分:秒（估算/最终状态）、正文、语气与停顿、画面开始/变化/结束、同步意图、来源。没有实测时间时保留估算标签；不复制手工维护正文。
3. 与01按同一真实材料完成关键单元设计：明确语言与画面分别承担哪些信息，哪些动作完成点需要留白。01改稿，03改shots，更新阅读视图；正文最终审核前完成此对接。
4. 建立一处 Remotion 环境。依赖变更/安装按当次授权执行；不能直接复制旧 package.json 中的个人浏览器命令。没有运行条件时仍可完成设计与代码，渲染状态明确未验证。
5. 定义最小场景接口：局部帧、时长、画幅、内容/资源输入；导入本期场景并注册总入口。只抽取本片已重复的组件，不创建万能场景 schema。
6. 先做一个看得见动作结果的无声场景，使用约定时长和关键画面预演；核对进入/离开或关系变化确实出现结束状态。无声预演不等待02完成，也不能算有声节奏已成立。

03A独立部分可先消费00格式示例完成设计入口、阅读视图和无声场景，不能因此声称真实内容已核对。步骤3等01提供真实内容后共同完成，不阻塞步骤4—6的独立开发。

03A交付：可用的设计入口、视听阅读视图、无声场景/渲染入口、与01的实际对接记录。真实无声渲染完成与否单独报告。

## 03B：有声预演、战场适配与合成

1. 接入02 timing和源音频，核对正文版本、音频指纹及时间精度；最终音频片段落在成片的哪里由 shots唯一确定。
2. 实现统一时间映射：原速下成片词时间 = 片段成片起点 +（源词时间 − 源入点）；只使用被选入源区间的内容，切点避开完整发音。统一转帧，镜头、音频和字幕共享同一边界；不得裁半个词后靠字幕补全。
3. 在真实音频上预演关键声画配合，明确源内停顿与新增留白。发现声音过快、动作未完成或读图时间不足，按总计划返回对应责任方；不随意拉伸旁白掩盖设计问题。
4. 适配战争场景：去除旧组件对演示 regions、map-data 和固定全片注册的绑定；用本期数据与明确输入接入新运行环境。只迁必要绘制实现，保留来源说明。按局部帧控制路线与军团位置，颜色/名称来自同一数据。
5. 把关键空间、路线、兵力与地形约束关联资料；技术演示可用明确标注的虚构数据，但正式历史验收须换为可回查依据。无足够空间资料时完成非地图部分，单列地图缺口，不用现代日本地图充当本期战场。
6. 将预演成立的故事与地图场景细化，建立本期最小视觉参考，统一角色、阵营、符号与空间承接。画面帮助推进信息，不要求每句重画一个场景。
7. 从同一映射生成字幕与成片，检查留白期间字幕是否应保留、最后一句及尾音完整、关键图形不被字幕遮住。独立 MP4 接入核对规格和自带音轨，避免重复旁白。
8. 输出MP4与可编辑工程，先核对格式/时长，再抽帧与连续播放，记录实际观察的成片时间码。改后复查受影响镜头及衔接，不反复播放未变候选素材。

## 验收与对外交付

| 检查对象 | 必须看到的事实 |
|---|---|
| 阅读视图 | 与实际正文、标注、shots相符；源变化后更新；估算与实测明确区分 |
| 提前对接 | 01与03使用同一稿件，必要信息由谁承担已写明；没有等音频生成后才首次考虑画面 |
| 原速时间映射 | 插入留白后源时间不变，字幕和相关镜头正确后移；相邻帧边界无累计偏差 |
| 叙事场景 | 连续画面中能看到开始、行动与完成结果，不能仅凭关键帧判断动作 |
| 战场场景 | 谁在哪、走哪条路、受什么地形影响可理解；轨迹与军团位置一致、来源/演示标识明确 |
| 有声短片 | 实际音频+故事场景+战场在同片；末句、停顿、动作、字幕共同成立，保留播放/听查证据 |
| 更新范围 | 只改构图复用音频；新增留白重映射字幕；换音频后相关时长和同步重新核对 |
| 无声/外部素材 | 不强制配音；可按明确时长独立交付，外部片段音轨处理明确 |

交付04：真实命令、输入/资源定位方法、短片工程、阅读视图、最终输出、检查与未完成项。03不负责重新定义内容审核、TTS缓存或项目总路由。

如果只有模拟 timing，最多说明时间计算已核对；如果只渲染未播放，最多说明产物已生成；如果战争数据是演示，只能交付技术演示。以上不能相互替代。

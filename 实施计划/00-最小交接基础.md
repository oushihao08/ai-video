# 00：最小交接基础

状态：共享解析、摘要、审核依据和三类变更失效范围已在正式稿及隔离副本验证；未覆盖所有可选字段组合。后续消费者：01、02、03、04。

先读[实施入口](README.md)及总计划第3、4、10节；给 agent 的规则按 writing-prompt 编写。本包只建立实际共享约定和少量共用读取能力，不实现六个 Skill、TTS 或渲染器。

## 目标与文件

让不同实施包对正文、表达标注、审核有效性和时间的理解一致。新建目标：

- `story-studio/README.md`：集合入口、各包当前状态、旧战争 Skill 的外部文档依赖。
- `story-studio/references/handoff.md`：一次定义交接字段、路径、摘要与失效规则。
- `story-studio/runtime/shared/content-contract.mjs`：正文/标注提取、内容与表达摘要、审核依据匹配；使用 Node 已有能力。
- `story-studio/examples/contracts/`：一套很短的格式示例及其说明，标为演示输入，不放入优秀样本库，不伪装真实审核、音频或史料。

以上是拟建路径，具体导出函数签名在实施时写入 handoff，与消费者同时采用；不预设尚不存在的可运行 CLI。

## 实施步骤

1. 核对当前目录与用户修改；从总计划抽出实际跨包信息，写 handoff。先固定 ID、文本提取、路径根目录、时间单位和审核摘要语义，避免后续各自选择。
2. 用一个短演示稿具体定义 Markdown 约定：稳定段落 ID、句子 ID、可朗读正文、独立表达标记。删除标题、来源引用和指令后能唯一提取口播；同一句改措辞时保留 ID，拆合句时显式更新引用。
3. 定义下面的最小数据形状，在示例中填具体值。JSON 字段名在 handoff 固定后各包共同使用；示例估算时间与模拟音频不得标为实测。
4. 实现共用的文本提取与摘要函数；正文摘要覆盖有序的句段 ID 和正文，表达摘要覆盖目标句段与有效标注。句子级 TTS 缓存还要覆盖其实际合成上下文，由02负责。
5. 实现审核依据匹配的公共能力：检查审核对象、结论、当前输入摘要和未解决问题；显式用户冻结依据走单独分支，不伪造 `passed`。程序不评价故事质量。
6. 用演示输入检查设计边界，更新共享说明。完成接口交付后才允许各包独立编码；不要继续预建工作流状态机或自动迁移层。

## 必须固定的交接内容

| 对象 | 本包确定的最小内容 | 使用条件 |
|---|---|---|
| `episode.md` | 目标、事实/虚构类型、受众、停止位置、有效文件、当前阶段；当前要求设明确边界以便取摘要 | 单个已有稿可缺骨架，不能伪造骨架或来源 |
| `outline.md` | 主脉络、段落 ID、职责、必要解释、来源引用、估算或用户硬时限 | 新策划创建；外部定稿无需反向编造 |
| `script.md` | 稳定句段 ID、正文、表达标注及其作用范围 | 正文提取不得读出标注；无标注合法 |
| `review.json` | 审核对象与结论、问题位置/依据、未解决项、正文/实际骨架/要求/已用来源/规则摘要；需要时绑定视觉内容依据 | 缺省对象不填假摘要；`passed` 和用户明确冻结是不同依据类型 |
| `audio/timing.json` | 源音频 ID、文件与指纹、稿件和声音输入摘要、实测总长、句段源区间、时间来源和精度；可选逐字数据 | 不含成片偏移；缺逐字数据仍可有可靠句段区间 |
| `visual/shots.json` | 单元与句段引用、声音/画面分工、镜头状态变化、来源、估算时间；最终增加场景入口、帧范围、音频源区间与成片起点、同步点和留白 | 未配音阶段允许最终时间缺失；最终渲染必须完整；无声镜头允许无音频引用 |
| 视听脚本阅读视图 | 从正文、timing 与 shots组合，显示估算/实测/最终时间状态与输入摘要 | 03实现生成；不作为重复编辑真源 |

时间约定：源时间以秒、相对各源音频零点计；成片时间以项目帧率下帧边界计，秒转帧统一 `round(seconds × fps)`。相邻镜头共用边界。最终音频放置在03处理；02不提前把源时间改成全片时间。确定资源路径统一相对本期工程根解析，共享规则与 runtime 从集合根定位，不依赖调用时 cwd。

审核不直接对整个 shots.json 作内容摘要：时间回填或构图微调不应使正文审核失效。handoff 列出影响内容的部分（声画分工、视觉事实、必要信息、相关来源），与纯时间/样式字段分开取依据。语义改变需复核；只有时间变化重查同步，不默认重审全文。

## 交接与验收

| 场景 | 所需证据 |
|---|---|
| 带标题、出处与表达标注的稿件 | 提取结果只含应读正文；句段顺序和引用一致 |
| 改正文、只改表达、只回填镜头时间 | 分别影响内容摘要、声音输入摘要、剪辑信息；不会把所有改动混为全文过期 |
| 旧审核对应新正文 | 依据匹配拒绝放行；单纯写 `passed` 不足以通过 |
| 外部冻结稿 | 必须有用户决定的实际记录与所对应正文；演示记录不能成为生产授权 |
| 源音频加成片留白 | 示例能表达源区间不变而成片位置变化；不能混用秒与帧 |
| 无声或尚未配音 | 能表达设计状态，不能误报告满足有声渲染条件 |

本包不验收真实审核判断、TTS、动画或播放。共享函数执行检查受当次授权约束；仅审阅文档时标记实现/运行未验收。交付给各包：handoff、共享导出清单、示例目录和实际检查结果。

如果某字段暂时无真实消费者，暂不抽象；如果01或03发现字段无法表达必要内容，回到本包集中修订并通知消费者，不能各加一套名称。

# 格式示例

本目录仅展示如何把段落、口播句与声音表达标注分开。`script.md` 是虚构格式示例，没有来源、独立审核或用户冻结决定，不可直接用于正式 TTS。

新本期将有影响的用户原话与更改保存到 `requirements.md`，作者选择另记；验收场景定义不能冒充用户原话。审核以 `requirementsSha256` 绑定有效要求，`basis.contentPrinciples` 可用按路径排序的 `{path, sha256}` 数组，列共同原则、实际专项与相关参考（路径相对集合根）。旧单对象仍可读取；不能复制示例摘要伪称通过。组织方法写在现有骨架或记录中，不新增风格枚举与第二份正文。

`shots.json` 与 `timing.json` 展示当前每句独立源音频的字段及源时间与成片时间的分离；其中的文件名和时间都是模拟值，不指向真实音频或可渲染场景。声画设计由 story-video 在本期 `visual/shots.json` 完成；本目录没有真实音频、实测时间、审核通过记录或历史事实。可供视频入口消费的无声示意见[episode-demo](../episode-demo/episode.md)，它仍不是正式一期。

# 六类固定创作任务

这些是执行计划所需的验收场景定义，由实施者设置，不冒充额外用户原话。共同材料见 `materials.md`。每项约 60–90 秒为本次对照的编辑预算，不是生产硬时限；先交有句段 ID 的播讲正文、必要表达标注与简短组织说明。无分镜、无配音，不扩充材料。保存第一稿，独立审核后才修订。

## 01-cinema-satire

用 F1 做一段嘲讽评论，评论对象是影城的宣传与实际做法，给普通观众一种“这套话术真会算”的荒诞感。内容里让完全虚构的身份可辨。表达方式自行选择，不预设先给观点、反问开场、强烈愤怒或结尾升华。

## 02-cinema-plain

用同一份 F1，平静说明影城宣传、放映记录和回应之间的情况，给普通观众足以理解这段设定的信息。不作嘲讽，不额外捏造消费者反应。虚构身份可辨，不机械要求双方各占一半。

## 03-hongmen-history

用 H1 讲清刘邦如何通过项伯和张良的关系获得转机，随后在宴席中经历什么、怎样离开。让观众跟得上具体人物与行动，采用历史叙事；不借后来胜负裁判所有人的智商，不添加内心独白。

## 04-song-restaurant

用 H2 做一段历史生活内容，让观众看见记载中繁忙食店如何点单、传单、上菜以及出错的后果。叙述方式自行选择，不预置危机、逆袭、幕后秘密或宏大升华；没有材料支持的微观场景不编成史实。

## 05-hongmen-satire

用 H1 做一段带嘲讽的历史评论，关注宴席中范增、项庄、项伯行动之间的错位。应保持史料中的行动与归属，让观众理解讽刺落点；不捏造项羽公开下令杀刘邦、人物心理或某人必然导致后来的天下归属。

## 06-queue-mechanism

用 F2 给普通人解释过号后回来如何重新进入叫号顺序。用材料中的编号例子讲清“不能打断正在办理”与“不是自动排在末尾”的关系。不作嘲讽或历史讲述；标明这是示例规则，不当成现实窗口的统一政策。

# 虚构示意：封闭的渡口

## [seg-01] 发现封闭并改道
[s001] 先看一个完全虚构的例子：一支小队沿着河岸赶路，计划从旧渡口过河，在天黑以前到达对岸的营地。
> 表达 [s001]：平实交代目标，不加紧张语气。
[s002] 走到岸边，他们才发现渡口已经封闭；地图上的旧路线仍在，却不能再照原计划走。
[s003] 领队先让队伍停下，核对河岸和手里的路线图，没有让人冒险直接涉水。
[s004] 他沿河往上游找更窄的河段，决定改走一个新的渡点，把所有人带到同一处重新过河。
[s005] 画面先标出关闭的旧渡口，再把新路线画出来；这段动画只解释虚构队伍如何改道。

## [seg-02] 两路接近营地
[s006] 过河以后，队伍分成东、西两路，目标都是河湾后方的营地。
> 表达 [s006]：略放慢“东、西两路”，让观众先分辨两支队伍。
[s007] 东队沿着高地边缘前进，西队贴着河湾绕行；河流把路线隔开，也限制了他们能往哪边走。
[s008] 地图上的虚线表示计划路线，圆点才是队伍此刻的位置；路线逐步展开，不能把还没到达的地方当成既成结果。
[s009] 镜头跟着两支队伍向前，先保留各自的方向，再看它们在营地前逐渐靠近、汇合。
[s010] 到达以后，队伍还要清点人数和补给；地图能讲清移动过程，却不能替他们完成检查。
[s011] 这一切都是虚构的。读一张示意地图时，先找起点、障碍、路线和终点，再判断它实际说明了什么。
> 表达 [s011]：收束时保持克制，强调画面与结论的边界。

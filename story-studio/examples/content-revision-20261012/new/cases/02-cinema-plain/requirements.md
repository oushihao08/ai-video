# 本期要求

## 验收任务定义

来源：../../../tasks.md 的 02-cinema-plain。以下为实施者设置的验收任务定义，不冒充新增真人用户原话：

> 用同一份 F1，平静说明影城宣传、放映记录和回应之间的情况，给普通观众足以理解这段设定的信息。不作嘲讽，不额外捏造消费者反应。虚构身份可辨，不机械要求双方各占一半。

共同交付条件：约 60–90 秒是本次对照编辑预算，不是硬时限；有句段 ID 的播讲正文、必要表达标注及简短组织说明；无分镜、配音；仅用固定材料，保存首稿，独立审核后才修订。

## 作者选择

先交代虚构身份与放映时间，再说明回应两部分；对名称与记录的关系作平静归纳，不沿用嘲讽稿的预设态度或修辞。两稿独立构思，未读取旧规则稿。

实际方法：只采用共同内容原则与 story-plan/story-write 的通用策划写作；未采用 story-satire 或 story-history。

没有新增用户反馈、冻结决定或对内容的用户认可记录。

# 本期要求

## 验收任务定义

来源：共同任务文件 `../../../tasks.md` 的 05-hongmen-satire。以下为实施者设置的验收要求，不是新增用户原话。

> 用 H1 做一段带嘲讽的历史评论，关注宴席中范增、项庄、项伯行动之间的错位。应保持史料中的行动与归属，让观众理解讽刺落点；不捏造项羽公开下令杀刘邦、人物心理或某人必然导致后来的天下归属。

共同交付条件：本次编辑预算约60–90秒，非硬时限；给有句段 ID 的口播正文、必要标注和简短组织说明。材料只用 `../../../materials.md` 的 H1，不外补；保留首稿，不读取旧稿，独立审核后再修订。无分镜、配音或审核通过凭据。

## 作者选择

以范增的具体安排与其落空之处组织评论：项羽未响应，项庄执行，项伯挡住。冷述行动，加“各演各的戏”“同一场、两种用途”的比喻，关注本席的不一致；不外推为谁毁掉天下、不安排统一智商排名。历史方法用于说明人物关系、前夜善待约定与当场阻挡，避免把错位误说成项羽发出共同杀人指令。

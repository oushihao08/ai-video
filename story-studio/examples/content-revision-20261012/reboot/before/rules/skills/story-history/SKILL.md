# 历史叙事

从本期关注点与史料中选择可感知的行动、关系和细节，让观众理解或经历这段历史。人物、事件、生活、制度均可使用；不预设战争、权谋、悲壮、逆袭或宏大结尾。

## 输入与职责

读取当前要求、实际材料、已有正文或骨架，以及 [共同内容判断](../story-plan/references/content-principles.md) 和 [交接](../../references/handoff.md)。原始要求、作者选择、史料记载、解释和例子分别保留身份；受众、尺度、语气、叙述位置与停止阶段按本期决定。

直接调用时按请求完成构思、正文或局部修改，采用 story-plan/story-write 的相同方法与文件约定；经阶段 Skill 读取时只提供当前阶段需要的方法，然后继续该阶段。不得互相递归调用，不建立第二套正文、总控或审核全链；配音与渲染不属本专项。

## 从史料选择叙述

1. 定本期所要看的变化、处境、生活细节或制度关系。选出承载它的材料，区分哪些是必要连接、哪些只增加知识量；背景仅在省略会使当前行动或关系难以理解时进入作品。
2. 对关键说法确认谁记载、记载了什么、作者与事件的距离，以及本期材料能支持到哪一步。单一记载不改写为全部历史；有实质分歧且影响本期判断时保留分歧，不能把核验过程逐条朗读。
3. 按关注点组织。下表是适用判断，不是必须填满的四套模板；可组合或采用材料更适合的其他顺序。

| 关注点 | 组织判断 |
|---|---|
| 人物处境与选择 | 找到选择发生时已有的信息、可见限制与实际行动，跟随它改变了什么；区分人物当时可知与讲述者后来得知。材料没有心理依据时，用言行与处境呈现，不补全知内心。 |
| 事件变化 | 选能改变局面的行动及其前后关系；按时间、人物交接或空间移动让观众跟得上。区分先后、原因与促成条件，不把一次转机写成后来结果的必然起点。 |
| 日常生活 | 选物件、动作、服务或交往关系中可辨的细节，沿实际过程、空间或感知展开。具体到材料支持的尺度，不为“有故事”编造某个人、某一天、危机或反转。 |
| 制度运作与影响 | 追踪一项规则怎样经具体角色或环节产生结果；区分规定、记载中的执行与个别实例。对照只有在材料足够且能解释本期差异时使用，不从一例推出整朝通行。 |

4. 检查连接：关系为何能把行动连起来，正文或已明确设计的画面是否给了必要信息。遇到缺口定向回查；无法核实则收窄说法或保留未知，不用顺滑过渡代替证据。

## 写成可听见的内容

- 让具体动作、物件、关系与变化承载本期效果。需要解释时在听者需要处解释，不先灌朝代百科；专名、身份与术语只交代足以跟上当前内容的部分。
- 保持史料记载、推断和文学表现身份清楚。未记载的对白、心理、精确动作与场景不冒充史实；生动比喻若会产生新的事实含义就改写。授权历史虚构或改编先明确作品身份，再在授权范围创作。
- 当代评论可以参与叙述，但不以后来胜负裁判当时所有选择的智商，不用英雄标签替代行动。因果复杂时只展开影响本期理解的条件，不压成一个人的性格决定一切。
- 结束于本期内容实际完成处：行动、生活细节、制度结果、判断或有作用的开放处均可。不统一要求升华、胜败评语、反问或“真相永远未知”。
- 有嘲讽目的时读取 [story-satire](../story-satire/SKILL.md)。在骨架简记整篇主要怎样组织、另一方法在哪些材料上起作用；史料约束实际说法，不要求完整年代线与每段反转同时成立。

## 自审与交付

直接读正文：观众是否能跟上本期人物与行动、生活过程或制度关系；关键连接有何依据；是否结果倒推、争议定论、补造细节；背景和表现是否服务本期。按具体句段修正，不把节奏快慢或悲壮与否当统一质量标准。

沿用同一 `requirements.md`、`research/`、`outline.md`、`script.md` 与 `episode.md`；只生成请求需要的文件，句段 ID 与表达标注遵循交接。记录采用的材料、方法分工与未解决项。作者自审不写独立通过；新写或实质改写 AI 正文交现有 story-review 独立审核流程，修订后复核受影响项，不另建专项审核链。请求只到稿件时，在内容阶段停止。

# 内容判断与方法选择

适用于策划、写作、审核和总控。先确定当前任务，再采用适用方法；本文件不规定作品结构。

## 要求、依据与例子的身份

- 条件优先级：用户当前要求 → 本期任务 → 适用参考或配置 → 工具能力 → 模型默认判断。保留有影响的用户原话与更改，区分用户要求、作者选择、材料事实、示例和交付要求；作者的重述不得替代原始目标。
- 来源约束实际可说的事实。材料与预设说法相反时修正说法并说明，不通过偷偷更换评论对象或主题解决；材料的归属、未知、争议、推断和授权虚构各保持身份。
- 受众、体量、切入点、叙述位置、情绪、组织顺序和结束方式由本期任务决定。普通缺项自主判断并注明会影响结果的假设；仅核心目标或必要输入仍缺失时询问。
- 模板和样本展示办法。只读取当前有用部分，不继承其题材、数量、时长、人物、开头和结尾；技术演示或自产稿不自动成为优秀范文。

## 方法选择

| 本期任务 | 适用方法 |
|---|---|
| 嘲讽、反讽、辛辣评论 | 读取 [story-satire](../../story-satire/SKILL.md)，从构思参与，不只在成稿上换语气 |
| 历史人物、事件、过程或生活 | 读取 [story-history](../../story-history/SKILL.md)，按史料和关注点组织，不默认战争、权谋或悲壮 |
| 用嘲讽讲历史 | 采用两者有作用的部分：按主要创作目的组织全篇，另一个方法约束或辅助相关部分；在骨架简记分工，不生成两篇再拼接 |
| 激昂、悲伤、共鸣等情绪，未要求嘲讽 | 根据内容与要求安排态度和表现，不自动采用嘲讽或愤怒 |
| 没有匹配专项 | 直接按本期要求策划与写作；不强塞专项或回退为统一的解释报道 |

直接调用专项与经阶段 Skill 调用，使用相同正文和交接；阶段内读取专项方法后继续当前阶段，不能互相递归调用。专项不自签独立审核，也不负责配音或渲染。

## 从材料形成作品

- 选取能够承载本期理解或感受的具体对象、行动、细节、关系与判断。说明为什么值得讲，落实到实际表达，不用“有深度”“有情绪”等评价词替代内容。
- `mainNarrative` 说明本期内容连起来如何成立：可以是事件、评论、机制或场景，不要求填写主体—处境—发展—结果—未知的槽位。骨架是当前构思；写作发现更有效的组织可同步修正，改变核心目标须先处理该决定。
- 材料进入正文取决于其作用。背景、时间线、来源介绍、核验过程和未知不因已研究就必须朗读；省略会误导的归属和限定在需要处说清。评论不因准确性要求而自动变成机械平衡，真实反证不能隐去。
- 听者应能理解实际主体、指代与必要连接。关键原因、条件或结果只在影响当前理解时展开，不要求所有题材交代同一套关系、代价或机制字段。
- 段落可承担信息、行动、感受、铺垫、停顿或回味，按实际作用判断。问句要有作用，已能说明的内容不靠连续提问拖延；未知可保留，不能用“值得深思”替代内容。不得反过来统一要求先结论、反转、金句、短句、高潮、号召或闭合结尾。
- 声音和画面可以分担表达，但必要信息交给画面时须有具体设计，审核不能假想它已经实现。独立音频需在声音中兑现自己的承诺。表达标注说明重点、态度和停顿的作用，不平均分配情绪或用标签冒充表演。

审查规则时替换题材、对象、情绪和时长：规则若仍强迫原样本的讲法，改为有适用条件的判断。问句比例、禁词表和统一审美评分不能证明内容成立。

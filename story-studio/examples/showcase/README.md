## 展示约定

- 一次只改一个主要变量时，放在同组比较，例如同稿件不同画风、同音色不同读法。
- 每条保留日期、文字/来源、配音读法、视觉方案和实际媒体；草样明确标注，不把技术可行说成效果通过。

- 被用户选中的做法只作为该具体经验的参考；只有多种题材反复成立后，才写成通用 Skill 判断。

# 视觉方向：墨线与透明颜料

观众跟着刀口看，不跟着讲解者看。画面用洋葱横切面的近景和有手感的斜刀线表现受力；内层轮廓随压迫变形，刀锋真正穿过后，先让一团轻薄、半透明的雾扩开，再让较大的液滴沿弧线甩出。两个动作有明确先后，也有不同尺度和速度。

接着镜头靠近破开的组织。浅色气雾继续向外流动，几笔赭黄色的细墨线从破口进入气流，表示来源所述的含硫刺激物被气溶胶带入空气；这只是原理演绎，不是分子结构、实拍微观影像，也不表示可见液滴本身就是刺激物。末段用同一画幅里的两次切割对照：宽钝刀快速下压时飞散较多，细锋刀慢速通过时飞散较少；随后视线留在轻而稳的一刀上。

美术采用暖纸底、稀释的灰紫与赭色水彩、深褐手绘轮廓和略有抖动的笔触。墨迹负责动作的方向和边缘，透明色层负责压力、雾与气流。场景不画厨师、哭泣者或家庭实测，不使用剪纸舞台、炭笔底纹、照片背景、静态信息卡或未被来源支持的数值。

`shots.json` 中所有时间都是制作估算；目前没有实际配音和词级时间，不将镜头落点表述为语音同步。四个句子 ID 仍严格对应 `script.md` 的 `s001`–`s004`。

# 本期要求

## 用户要求

- 处于内容创作 Skill 套件的探索阶段；持续提供能观看、试听和比较的内容、声音、动画及美术方向。
- 样片按日期和方向放进展示区；没有反馈时保持待选并继续新的对照，不把沉默当作认可。
- 可在 X 查动画作品或制作过程，并查看计划文档的方法建议；用户允许调用 agent 完成独立子任务。
- 以同一篇口播、同一主音轨为基础，给出多种差异明确的动画表达；另提供不同读法的短音频供比较。
- 动作要能被看见、读懂；结构与风格不能固定成每期模板。技术渲染成功不等于用户审美验收。

## 作者选择

- 选沈括《梦溪笔谈》所记毕昇活字印刷，聚焦两块铁板交替工作、泥字制作和印量与效率的关系。
- 本组动画比较真实材质加合成动作、炭笔线条跟拍、全 SVG 剪纸动作舞台三种路径。
- 三条动画共用“朋友聊天”音轨；另外两种语气只做音频试听候选，不改变文字。
- 所有画面均作为本期视觉演绎，不声称复原宋代现场或器具。

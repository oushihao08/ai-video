# 视听方向：测试记录与空白维修单

- **形式**：冷静、锐利的动态编辑图形。用硬边网格、编号、细线和短促位移组织信息；炭黑、浅灰白为底，信号橙只标测试结果与需要观众注意的空格。避开纸偶、手绘质感、主持人讲解卡和统一新闻模板。
- **观看路径**：观众先看三条抽象制动带上的车标记停下，再看到三个对应的部件符号断开；画面压成并列的“测试报道”与“尊界声明”两栏。第二句从标明“客服转述 · 预计”的虚线时间点开始，最后转到一张明确写着“想象 / 示意”的维修单。
- **声画分工**：口播交代事件与原话；动画负责建立三车与部件的对应、分开各层来源，并让维修单的已知栏和空白栏形成一眼可读的反差。画面不补充工程原因或责任判断，也不重演真实测试。
- **来源层级**：第一段结果只标“测试报道”；回应卡标“尊界声明”，原话按引号呈现；进度线标“客服转述 · 预计”，使用虚线且不显示已完成状态；维修单标“想象 / 画面示意”，其现象行注明“测试报道所述”。不画品牌标志，不把客服转述画成官方方案已确认。
- **逐词同步**：镜头 1 的三车在“连续急刹”后依次刹停，部件符号在“踏板支架底座”出现、“都断了”时断开；声明卡从“尊界当天称”进入，原话与两项后续安排分别跟随实际说到的词。镜头 2 的两个虚线节点分别在“预计月底确认”和“十一月起 / 陆续升级”出现；维修单在“想象一张维修单”进入，故障现象在“故障栏写清楚了”时填入，更换部件空框在“换什么件”时出现，并在“那格还空着”后保持可见。
- **剪辑时间**：30 fps。s001 源长 13.224014 秒，放在第 0 帧；换句留 5 帧（约 0.17 秒）呼吸后，s002 从第 402 帧开始，源长 11.064014 秒。第 734 帧后留 21 帧（0.7 秒）静止尾帧，总长 755 帧（约 25.17 秒）。字幕使用公共渲染器的真实词级字幕，不在场景里重复制作。
- **边界**：车与部件均为抽象符号，不按实物比例或真实结构复原；“故障现象”只表示报道描述的测试结果，不构成根因、用户车辆状态或监管鉴定结论。画面文字和关键动作留在底部字幕安全区以上。

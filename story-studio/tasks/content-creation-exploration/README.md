### 验收标准与边界

| 验收项 | 本次证据 |
|---|---|
| 创作核心有可执行判断 | 规则能要求作者以作品中的具体处境/反差/发现说明吸引力，并改变材料取舍、顺序与揭示；不强制冲突、主角成长、三幕、反转、语气或时长 |
| 原始目标不会被作者覆盖 | 要求和作者选择分开，审核核对可信任务；作者自定“原理说明、克制”等不能自动成为用户要求 |
| 口播与声画能共同创作 | 有说话动作、表演意图、观众信息顺序和可实际制作的关键动作；默认音色与默认场景不决定风格 |
| 审核不以正确/新增信息放行创作任务 | 新材料审阅给出具体文本位置、预期与兑现、缺陷/限制；无趣或任务未实现可以判需修改，摘要不代替判断 |
| 规则具备初步迁移证据 | 三种新任务有真实正文和隔离审核，结构与态度随任务变化；只证明本次生成/改稿表现，不证明稳定优越 |
| 下游接口保留 | 八个本机入口仍指向项目，正文可由现有解析器读取，无运行层/依赖改动；关键声音/粗预演按真实审核与时间运行 |
| 结论没有超出证据 | 文件修改、文字判断、实际媒体、听查、用户认可分别报告；本次不验收全题材稳定质量、听感自然、传播效果或用户满意 |

计划写入原有记录，执行后保留本任务与原正式计划，不另建临时计划文件。旧样片按本次用户反馈记为否定；旧审核保留为历史，不刷新摘要冒充复审。

## 目标

先用可观看、可试听、可比较的作品找出内容创作中真正有效的做法，再把经过用户选择和跨题材复验的经验沉淀成一套统一核心 Skill，并按需接入嘲讽、历史叙事、动画表达、声音表演等外围专项。核心共用同一套创作判断与交接，不规定每期必须使用的开场、故事弧线、情绪或画风；专项改变本期方法，不另造一份全链路和第二正文。

探索重点是故事为何值得听、听众跟随什么行动/变化、信息如何推进、结尾是否有着落，以及声音和画面怎样共同表达。不要用连串问题、空泛铺垫、课堂总结或“看起来很深”的句子冒充故事；结构是检查工具，不是写作模板。动画方向须在动作、构图、节奏或揭示方式上有区别，不以配色和转场差异冒充新风格。

## 工作方式

1. 从用户要求和真实材料出发，选择适合本期的叙事入口；事实、推断、作者选择分开记录。需要上网时保存可回查的原帖/官方来源，并写明实际看到了什么、未看到什么。
2. 形成短口播和声画意图，检查事实、听众关注及推进是否成立；正文由独立审稿者阅读后再进入配音。具体用户反馈作为新约束，失败版本保留为反例。
3. 生产可比较的短配音、动画/美术样片。同稿试画面时尽量锁定声音、时长与正文；同时改变多项时，清楚说明无法归因给单一变量。
4. 每件作品保存原始要求、选题理由、材料、构思、正文与改稿记录、独立评审、配音读法/真实时间、导演意图、分镜与场景源码、资源来源、运行参数、实际媒体和检查范围，使作品可追溯、可复做。
5. 所有样片按日期进入[展示区](../../examples/showcase/README.md)，区分草稿、预演、完成、待看/待选、已选、待改和否定。用户没回复时保持待选并继续追加，不把沉默记成认可。
6. 暂不把一次样片或一次审核直接改写成通用 Skill。用户选中的方法先记录为本期偏好；方法在不同题材、不同视觉或讲述条件下重复成立，并经用户认可后，再决定归入核心还是外围专项。

## 单批验收

一批样片只有在声明阶段的实际交付完成后才算该批完成：

- 声音样片可播放，有脚本、读法说明、真实音频时长/时间依据；未实际试听时标为未听查。
- 动画样片有可播放媒体、源场景/分镜、创作路径、素材出处、渲染来源信息；抽帧或解码结果只说明对应技术检查，不代替连续观看或用户接受。
- 对照说明本批改变的变量；引用链接能定位原帖/官方材料，方法主张不超出可见证据。
- 展示区与本任务状态同步；等待用户选择不阻塞后续探索。

这些标准判断产物是否真实、可追溯、可比较，不判断用户是否喜欢、是否传播成功，也不把单条样片合格当作核心 Skill 已成立。只有用户明确选择、反馈被落实且通用做法经过跨题材检验后，才开始沉淀对应规则；目标保持 active，直到用户决定停止或另行调整。

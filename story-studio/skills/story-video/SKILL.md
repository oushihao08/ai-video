# Story Video

先读集合 `references/handoff.md`、当前要求/`requirements.md` 与本期 `script.md`。完整视频在正文定稿前读取 `outline.md` 中实际创作方法，与 story-write 核对关键表达的声画分工；已有稿、音频、无声任务按实际输入进入，不补造缺失的骨架、审核或逐词时间。

## 设计

1. 以实际信息、行动、感受或注意变化划分 `visual/shots.json` 的单元与镜头；铺垫与回味也可有作用，不要求每镜新增事实。每个单元引用真实句子 ID，现有 `newInformation` 字段描述其实际作用，`visualRole` 写声画分工；镜头写开始、变化、完成状态与同步意图。稿件只在 `script.md` 编辑。
2. 配音前写估算时长。已有可靠 `audio/timing.json` 后，记录每段音频的源入/出秒数和成片起始帧；新增留白只占成片帧，不改源时间。需要词级同步时先确认有词级数据；仅有句级时间只能实现句级同步。
3. 在现有 `visual/direction.md` 简记本期导演意图：观众跟谁看、画面独立承担什么、关键揭示与反应何时发生，以及实际需要的角色辨认、空间方向与示意标识。不逐项填无关栏目。路线、部署、兵力、地形与关键动作若影响结论，关联 `research/` 中具体来源；依据不足时标示示意，避免精确复原暗示。
4. 用 `runtime/remotion/cli.mjs prepare <episode>` 生成 `output/视听脚本.md`，直接核对声画对应关系。该视图是派生文件，源文件修改后重新生成。

镜头围绕观众关注与关键变化创作，工作流程/物体运动本身不证明故事成立。先决定观众站在哪里、先注意什么、接下来看到的行为怎样改变理解或感受；必要时让前景行为和背景信息构成反差。角色通过怎样做事表达意图与个性，视线、预备、犹豫、动作力度、反应及停留按本期选择；没有人物也可用构图、物件尺度和有意义的对照揭示发现。纪实未记载的表情/反应不能假装真实复原。

口播、动作和字幕各承担具体作用，避免逐项同步复述。文字标签负责辨认，行为、调度和镜头负责可见表达；美术媒材服务这种表达，不把换配色或流畅运动当成新叙事方法。记录到现有direction和镜头字段，不新增导演表格或场景框架。

先把关键画面与临时声音按实际节奏组成粗预演，再做精细渲染。低细节也要能读出关注、行为意图和变化；记录观众在哪一刻发现、误解或反应，不只检查字幕同步。关键设计落空先改声画组织与正文，不能靠增加质感补救。没有实际听辨能力就交待听粗片，不批量扩大精细版本；明确要求完整待验媒体时可以继续，但效果缺口保持可见。默认场景、配色和切镜方式是工具能力，不是默认风格。必要反语若依赖语气或画面才成立，须在预演兑现，文字标注和源码不能代替效果。

字幕显示单元与合成单元分开。核对分句字幕的真实词级依据；句级回退不能保证多句正文中的包袱不提前出现，关键揭示需补可靠对齐或调整剪辑。画面中的文字、图标和道具同样可能泄露结果，须与声音一并检查。字幕密度、字号和安全区以本期画幅与实际画面核对；不要用缩小整段字挤进画面代替切分。

## 制作与检查

- `visual/shots.json` 消费方式和实际命令见 `runtime/remotion/README.md`。内置 `story` 场景表现“障碍出现→改道→抵达”的完整动作，`battle` 场景消费本期阵营、地形、路线与军团数据，`video` 场景接入本期已有视频并明确源音轨取舍。需要本期专属画面时，在 `visual/scenes/index.jsx` 默认导出单文件 React/SVG 场景，用 `scene.type: "custom"` 与 `scene.data.key` 引用；组件可用实测词级时间映射出的 `speech` / `cueFrame(sentenceId, phrase, edge)` 对齐关键揭示；没有逐词时间时不可宣称精确同步。实际渲染前核对组件出口和连续动作。按本期内容改 `scene.data`，不要把默认示意文案或地图当历史事实。
- 地图任务同时读 `/Users/jack/Documents/codes/lvgou/ai-videoxxx/map-demo/skills/historical-war-map-video/SKILL.md`。它提供地图叙事、证据和绘制约束；本期场景在新 runtime 绘制，不调用旧 `map-demo/render.sh`。
- 精细制作前先看关键片段的实际动作完成状态；有声片同时听句子、停顿和留白。渲染、抽帧、连续播放与主观接受分别记录，不能互相替代。修正构图可复用音频；修改正文、声音或剪辑位置时重核对受影响的审核、源时间与字幕。
- 发现读不懂或动作时间不足，先调整镜头/留白；需要改变正文时返回 story-write 和 story-review，需要改变声音时返回 story-voice。不要通过拉伸旁白掩盖设计问题。

## 交付边界

无声片可用约定时长单独交付。已有音频必须有真实文件与足够的源时间；缺句级对齐时不生成伪字幕。有声成片验收必须实际听查和连续播放，并说明正式历史地图的资料依据。当前 runtime 的依赖、浏览器和工具须由执行环境明确提供；命令存在不表示已渲染成功。

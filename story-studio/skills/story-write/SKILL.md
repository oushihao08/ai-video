# 写作与口播表演

写能让人接到事情、态度和感受的话。正文、说话动作与关键声画共同创作，不扩写策划说明。

## 读取

先读可信当前要求、实际材料和 requirements.md，再读骨架/待改稿、[创作核心](../story-plan/references/content-principles.md)、适用专项与[交接](../../references/handoff.md)。保护外部原文及授权范围；不继承作者自选的克制、播报或旧样本口吻。

## 成稿

1. 选择具体说话关系与当下意图，把核心片段先说出来。讲述者可以兴奋、尖锐、温柔、迟疑或庄重，依据任务和事情变化；“自然”不是压低情绪，“接地气”来自可认出的处境、话和反应。没有授权不能伪装亲历或编事实。
2. 从选定进入点让观众接到值得跟随的内容。安排信息顺序，使听者有预期、参与发现并获得回报。身份、背景和术语在理解需要处补；不要用空泛铺垫推迟实质，也不为悬念隐藏基本处境。
3. 让人物怎样行动、对象怎样回应、关键事实怎样改变理解实际进入正文。每段可以铺垫、推进、转向、停住或回味，但要对当前承诺有作用。仅换名词、加事实、重复同一矛盾时重构，不用口语外壳填满骨架。
4. 写具体回应与有个性的措辞：人物/讲述者为何此时这样说，前一句怎样使后一句发生。字句须能说出口、指代可跟随。反语让上下文、读法或行为支撑；不靠“这很讽刺”“人性如此”等标签说明效果。解释保留必要部分，已读懂的笑点和感受交给观众。
5. 与 story-video 对齐关键揭示，决定声音、动作、字幕谁先让观众接到什么；独立音频需自己成立。关键表达标注写积极的表演动作、重音转意、衔接和反应空间，不反复写“正常带过、不抬情绪”。特殊平读可以有创作作用，但必须由具体上下文决定。
6. 结尾兑现本期承诺，在真正的结果、发现、判断或余味处停下；必要判断直接给，不强加反转、金句或升华。写作发现骨架薄弱就同步删并重排，核心对象/目标改变返回策划。

## 正文接口与交付

script.md 是唯一正文：标题用“## [seg-01] 标题”，正文用“[s001] 口播内容。”，可另写“> 表达 [s001]：具体读法。”。一个ID按连贯说话动作与呼吸组织，可含几句；不遇句号就机械拆配音。改措辞保留ID，拆合时分配新ID并同步引用。研究、导演动作、时间和创作论证放交接文件，不进入朗读文本。

脱离骨架说明读最终正文，检查观众实际会接到什么：最有吸引力的内容是否出现，关键变化是否有分量，铺垫是否兑现，哪里冗长/平淡/装腔。要求某种风格时检查具体表达，不以备注中的风格词作证。正式、诗性等语体按明确任务，不强加聊天腔。

交付正文、必要读法、来源关联与缺口。AI新写/实质改写交独立 story-review，不自己签通过；只要稿就停止。文本成立不证明声音自然或包袱已演出来。

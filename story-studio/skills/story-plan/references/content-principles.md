# 内容创作核心

用于策划、写作、专项、审核与视听共同决策。目标是让观众愿意进入、参与理解并得到回报。资料准确、句子口语、画面运动都是能力，不是吸引力的证据。依据与转译见[电影故事方法](storytelling-foundation.md)。

## 权限与任务

- 按用户当前要求 → 当前任务 → 适用参考/配置 → 工具能力 → 模型默认判断解决条件。原话、事实、作者选择、示例分别保存身份。作者自定的“短、克制、讲清工序”不能覆盖用户的嘲讽、情感或故事要求。
- 纪实取舍、重排与评论不授权造事实。虚构须有授权且身份可辨。事实边界限制可声称什么；视角、比喻、取舍、节奏、态度和可辨的假想表达仍须实际创作。
- 结构、语体、态度、时长、画风按本期。下列方法按材料与目标使用，不是每篇必须包含的剧情条件或输出栏目。

## 找到值得看的东西

先找材料中会让受众产生具体反应的部分，再选进入点。人物在保住什么、谁承担了代价、习惯被哪一个事实打破、一个细节怎样暴露更大的矛盾，都可能是吸引力。必要时补材料或换切口；不要把薄材料加工成更长的流程。

在骨架中用作品里的事实/动作说明：观众为什么在乎这次结果或发现，以及这一讲法将带来什么。不能用“大家有共鸣”“这个知识有趣”“每句有新信息”代替依据。处境的重要性可以很小，但必须对人有具体分量；解释任务也可以靠有效的对照、验证或发现使认识改变，不需要编一位遇险的主角。

## 组织观众的经历

| 创作判断 | 怎么落实 | 常见失效 |
|---|---|---|
| 关注与承诺 | 让观众接到一件值得跟下去的事：具体处境、鲜明判断、意外结果、令人认得的反差或有感受的细节 | 只有主题介绍或“接下来告诉你” |
| 预期与参与 | 先给理解所需线索，让观众形成猜测、站位或感受，再用后续事实/行为发展或修正它 | 旁白提前解释全部意思；靠连续提问装悬念 |
| 有分量的变化 | 事件改变人物处境/可选行动；评论改变对对象的认识；解释改变直觉或做法。铺垫、停住和回味可参与这种变化 | 工序换下一步、对象移动、增加一个名词就宣称推进 |
| 因果与意义 | 有据的选择和后果相接；没有因果则保留对照或观察。问清这个变化对本期关注意味着什么 | 把时间先后写成因果；为“有故事”编阻力 |
| 铺垫与兑现 | 在观众能认出的细节/规则上落下结果，让前面的期待有回报；回扣使旧细节获得新意味 | 最后加金句、生活建议或意义总结，掩盖没有兑现 |
| 具体性与个性 | 用只有这件事才有的动作、物件、言语与关系做关键节拍。角色通过怎样做事可辨，讲述者通过实际回应可辨 | 换题材仍是同一份“先介绍—再解释—最后感悟” |

这些关系不是固定次序。已知结局、安静观察、直接评论、知识说明都可成立。短片可以只完成一次有分量的发现；不能因为缺少冲突、反转、成长就判差，也不能借“没有冲突”免除吸引力判断。

粗讲之后回看关键节拍：观众原先接到什么，接下来发生/发现了什么，为什么愿意继续。薄弱时改材料、视角、顺序或表达，不用创作说明替作品补魅力。内部判断不读进口播，不固定候选数或段数。

## 写与演是同一次创作

- 从所选进入点给实质内容；当前用户已否定“先别急着下结论”“先想一个问题”式空泛引导。有效的对白、疑问、直接表态仍按本期使用。
- 给每个关键单元一个能执行的说话动作：催促、袒护、拆穿、试探、炫耀、安慰等，选择取决于实际关系；写出相应的话。强弱、快慢、认真与反语可以变化，不默认低情绪或平均铺满情绪。
- 让声音、画面、字幕分担理解和感受。可见的行为或反差让观众自己接到意思；必要身份、知识和连接及时说明。不能为“电影感”删除理解依据，也不能为“清楚”解释已经成立的笑点和感受。
- 前一句的落点影响下一句怎样接；反应、停顿和未说出口的意思也是表达。单独音频须自行成立；完整视频可以由镜头和声音共同承担。
- 结尾在本期承诺得到回报处落下；未知结果保留具体处境，判断可以明确，余味可以开放。不要换词复述已完成的意思。

## 专项与执行

嘲讽读取[story-satire](../../story-satire/SKILL.md)，历史读取[story-history](../../story-history/SKILL.md)。专项提供不同的创作手法，复用一份正文和交接；混合时确定主要目的与局部方法，不拼两篇稿，不新增风格枚举。无匹配专项使用本核心。

关键声画先做粗预演，检查具体作用有没有兑现，再扩大制作。无人听辨时如实交付待听预演，不能用更多画风掩盖未确认的内容/表演。用户指出平淡、旧风格或不好笑后，返回生成选择，旧通过不继续作为效果依据。

改造验证用新材料真实生成并隔离审阅；具体例子只演示决策，不成为固定题材、结构、态度或时长。解析、摘要、格式检查验证交接，不评价故事质量。
